# 陆郁生 · 技能试炼场（网页版）

三国杀自定义武将「素心傲雪 · 陆郁生」的单机试炼场。
纯前端、零依赖、离线可用：银贞 / 洁霜 / 瑶心 三个技能按实体牌时点完整结算，
另外内置 7 名武将可以随意换将、人机对战。

## 在线玩

直接打开本站首页即可，无需安装。手机浏览器可用「添加到主屏幕」变成全屏 App。

## 玩法

1. 选将：左边点一个作为「你」，右边点一个（或点「随机」）作为对手。
2. 出牌阶段点手牌使用；技能触发时牌桌下方弹出提示条，点「发动 / 不发动」。
3. 顶栏「全屏」可全屏；手机上是右上角 ☰ 抽屉里的「全屏」。
4. 「观战」= 双方 AI 自动对打，适合观察技能联动。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个游戏（CSS / JS / 立绘全部内联，单文件 ~230 KB） |
| `manifest.webmanifest` | PWA 清单：名称、图标、全屏启动 |
| `sw.js` | Service Worker：离线缓存 |
| `icon-512.png` | 应用图标 |
